# spspan

직병렬 그래프의 신장 나무를 모두 만들되, 이웃한 두 나무가 변 하나만 다르게
늘어놓는다.

- 문서: [spspan.w](spspan.w)
- 바탕: 커누스의 CWEB 프로그램 `spspan.w`(2017)와 그 그림 `spspan.mp`(2003)

## 방법

- 그래프는 `----ps-sp--sp` 같은 역폴란드 식으로 받아, 직렬(S)과 병렬(P) 가지가
  층마다 번갈아 나오는 나무로 바꾼다.
- 가지마다 *지정 자식*을 하나 두면 신장 나무가 하나로 정해진다. 지정 자식을
  혼합 기수의 모듈러 그레이 부호로 돌리면 걸음마다 변이 하나 빠지고 하나 든다.
- 돌릴 가지는 알고리즘 7.2.1.1L의 초점 포인터로 고른다.

## 원본과 다른 점

- 포인터 산술 대신 노드마다 제 번호(`num`)를 적어 두고, 잎과 가지를 두 슬라이스에
  나눠 담는다. 크기는 식을 읽은 뒤 정하므로 원본의 `maxn` 한도가 없다.
- 셈 `mems`는 `main`의 지역 변수로 두고, 초기화 함수는 제 셈을 돌려준다.
- 원본의 결함 하나, 이항 연산자가 255개를 넘으면 나무 수를 틀리거나 세그폴트로
  죽는 것을 고쳤다.

## 검증

- 식 514개에서 세 가지 자세함으로 원본과 출력·mems·종료 부호가 바이트까지 같다.
- 나무의 수를 닫힌 점화식으로, 그레이 성질을 출력을 따라가며 따로 검사했다.

## 성능

나무가 7억 개인 식에서 원본 3.3초, 이 판 5.3초. 셈과 출력을 빼도 그대로라,
포인터를 쓸 때의 쓰기 장벽 검사와 경계 검사 탓으로 본다.

## 빌드

저장소 루트에서 부른다. 규칙은 [../Makefile](../Makefile)에 있다.

```sh
make spspan   # spspan/spspan.go + spspan/spspan.pdf
make clean    # 모든 예제의 생성물 삭제
```
