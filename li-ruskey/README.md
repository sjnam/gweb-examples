# li-ruskey

[koda-ruskey](../koda-ruskey/)의 속편이다. 이제 제약에 *방향*이 있으므로, 입력은
숲 포셋이 아니라 완전 비순환인 방향 그래프 아무것이나 된다. 할 일은 `x → y ⟹
비트 x ≤ 비트 y`를 지키는 0/1 라벨링을 모두, 뿌리 비트가 딱 한 번 뒤집히는
그레이 경로로 늘어놓는 것이다.

- 문서: [li-ruskey.w](li-ruskey.w)
- 바탕: 커누스의 CWEB 프로그램
- 그림: MetaPost 그림 넷
- 다음 읽을거리: [spiders](../spiders/)

## 방법

다음 것들로 무반복을 지키는 변두리가 나온다.

- 준양·준음 꼭짓점 집합
- 반쪽 경로 둘을 하나로 잇는 혼합 기수 반사 부호
- 딸림들과 전이 문자열
- 돌아다니는 플래그 뒤에 *낡은* 고리를 남겨 두는 것

## 코루틴 판

커누스는 코루틴 판을 연습 문제로 남기며 부모 포인터가 동적이어야 할 것이라고
했다. 옮긴 판은 그 연습 문제를 고루틴으로 푸는데, 거기서는 어려움이
증발한다(호출 스택이 곧 부모 포인터다). 코루틴마다 처음 깨어날 때 제 비트를 읽어
들어갈 자리를 고른다.

## 검증

두 구현이 한 프로그램 안에서 돌고, `-v` 출력까지 CWEB 원본과 줄 단위로 같다.

## 빌드

```sh
make        # li-ruskey.go + li-ruskey.pdf
make clean  # 생성물 삭제
```

규칙은 [../gweb.mk](../gweb.mk)에 있다.
