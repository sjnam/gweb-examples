# prime-sieve

에라토스테네스의 체를 구간마다 홀수만 비트로 담아 돌리며, 256 이상인 소수 간격의
기록을 찾는다.

- 문서: [prime-sieve.w](prime-sieve.w)
- 바탕: 커누스의 2017년 CWEB 프로그램
- 그림: MetaPost 그림 하나

## 방법

- 두 소수 사이에 모두 1인 64비트 낱말이 있어야만 간격을 자세히 본다.
- 32보다 작은 소수는 낱말마다 비트 무늬를 돌려 찍는다.

## 원본과 다른 점

- 커누스가 미심쩍어한 구간 경계의 간격 논리는, 구간 크기를 128까지 줄여 시험해
  보니 옳았다.
- 명령줄 검사의 결함 둘을 고쳤다. s₀²이 64비트에서 넘쳐 2³²의 배수인 출발점을
  거절하는 것과, 음수 t에서 0으로 나누고 배열 밖을 읽는 것이다.
- 이진 로그 표는 패키지 `math/bits`로 바꾸었다.

## 검증

- 원본은 파이썬 구간 체와 1197건에서 맞았다.
- 이 판은 원본과 621건에서, 고친 두 경우만 빼고 바이트까지 같다.
