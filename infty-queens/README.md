# infty-queens

끝없는 체스판의 가로줄마다, 앞의 여왕들에게 잡히지 않는 가장 왼쪽 칸에 여왕을
놓아 가는 탐욕 수열(OEIS A065188)을 계산한다.

- 문서: [infty-queens.w](infty-queens.w)
- 바탕: 커누스의 2017년 CWEB 프로그램
- 그림: MetaPost 그림 하나

## 방법

Sloane과 Shallit이 밝힌 황금비 구조 덕에 비트 벡터 셋에서 몇 칸만 보면 된다.
nφ의 분수 부분을 음 피보나치 표현의 비트 무늬로 들고 다니며 어긋남을 정확히
잰다.

## 원본에서 고친 것

- 원본 첫 문단의 정의는 수열을 q₀부터 세어, 프로그램과 첨자가 하나 어긋난다.
- 9φ의 예시 식은 첨자와 부호가 틀려, 적힌 대로 셈하면 5.51이 나온다.
- 음수 n은 거절한다.
- 13억쯤을 넘으면 int가 넘치던 배열 크기는 64비트로 셈한다.

## 검증

원본과 인자 317가지에서, 일부러 고친 음수 둘만 빼고 바이트까지 같다.
