# ntt

**고속 푸리에 변환**과 그 정수 사촌인 **수론 변환**으로 가는 친절한 길잡이다. 이
글이 향해 가는 프로그램은 Library Checker의 *Convolution (mod 998244353)*, 곧
O(n log n)의 다항식 곱셈을 푼다.

- 문서: [ntt.w](ntt.w)
- 그림: MetaPost 그림 셋

## 다루는 것

- 값매김–곱셈–보간이라는 우회로
- 제곱이 1의 거듭제곱근을 접어 문제를 절반으로 만드는 까닭
- 비트 뒤집기와 나비 회로
- 역변환
- NTT가 환에 정말로 요구하는 것(그리고 998244353 = 119·2²³+1인 까닭)
- 가우스(1805)에서 하비와 판데르후번(2021)에 이르는 뜻밖의 역사

## 빌드

저장소 루트에서 부른다. 규칙은 [../Makefile](../Makefile)에 있다.

```sh
make ntt    # ntt/ntt.go + ntt/ntt.pdf
make clean  # 모든 예제의 생성물 삭제
```
