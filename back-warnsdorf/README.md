# back-warnsdorf

나이트 투어를 찾는 *바른스도르프 규칙*(늘 덮이지 않은 이웃이 가장 적은 이웃으로
간다)을 따라 걸을 수 있는 길을, 동률의 갈림까지 모두 훑는다.

- 문서: [back-warnsdorf.w](back-warnsdorf.w)
- 바탕: 커누스의 CWEB 프로그램
- 필요한 것: [go-sgb](https://github.com/sjnam/go-sgb)(그래프를 `gbsave`로
  읽는다)

## 하는 일

- 길마다 동률을 무작위로 깨는 걸음이 거기 닿을 확률을 셈한다. 이를테면 8×8
  판에서는 어느 칸에서 떠나든 97–99퍼센트의 확률로 투어를 얻는다는 것을 알 수
  있다.
- 바라는 끝 꼭짓점을 적어 닫힌 투어를 노릴 수도 있다.
- 같은 꼭짓점을 두 번 적으면, 그것은 막다른 마지막 칸으로만 들어갈 수 있게 된다.

## 원본에서 고친 결함

후보 스택이 1000칸으로 고정이라, 꼭짓점이 1000개에 가까운 그래프에서
넘친다(3×330 격자는 멀쩡히 끝나면서 1319칸을 쓴다). 옮긴 판은 스택을 호의 수만큼
잡는다.

## 검증

원본과 450가지 경우에서 출력과 종료 부호가 바이트까지 같다.

## 빌드

저장소 루트에서 부른다. 규칙은 [../Makefile](../Makefile)에 있다.

```sh
make back-warnsdorf  # back-warnsdorf/back-warnsdorf.go + back-warnsdorf/back-warnsdorf.pdf
make clean           # 모든 예제의 생성물 삭제
```
