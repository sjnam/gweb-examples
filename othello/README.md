# othello

[othello.w](othello.w) — m×n 판에서 p명이 두는 일반화한 오델로(리버시)를
대화형으로 진행한다. 표준 입력으로 칸 이름(`d3`)을 받고, 뒤에 `!`를 붙이면 판을
찍는다. 처음 p²수가 뒤집기 없는 첫 배치이고, 판에 빈 테두리를 둘러 여덟 방향으로
훑을 때 경계 검사가 필요 없다. 커누스의 2024년 CWEB 프로그램을 옮기며 서술의
오타(표준 판이 "m=n=9")를 고쳤다. 원본은 `void main`이라 게임이 제대로 끝나도
종료 부호가 정해지지 않는다(clang -O2에서 10). 이 판은 0을 돌려준다. 판 크기와
경기자 수를 열두 가지로 바꾼 원본과 무작위 입력 7200개에서 표준 출력과 표준
오류가 바이트까지 같고, 표준 첫 배치에서의 perft 4, 12, 56, 244, 1396이 그대로
나온다. MetaPost 그림 하나.

## 빌드

```sh
make        # othello.w -> othello.go + othello.pdf
make clean  # 생성물 삭제
```

규칙은 [../gweb.mk](../gweb.mk)에 있다.
