# ziptree

타잔과 레비와 팀멜의 **짚트리**. 기하 분포 난수 *등급*으로 최대 힙 순서를 지키는
무작위 이진 탐색 트리이고(비기면 키가 작은 쪽을 민다), 회전 대신 탐색 경로를
*지퍼처럼 열고 닫아* 갱신한다.

- 문서: [ziptree.w](ziptree.w)
- 꾸러미: 라이브러리 `ziptree`(`main`이 없다)

## 세 표현

논문의 재귀적 insert, zip, delete를 라이브러리로 구현한 뒤, 메모리를 아끼는 두
가지를 이끌어 낸다.

- **아레나**: 첨자 기반, 등급 1바이트, 빈칸 목록. 마디 크기를 절반으로 줄이고,
  백만 마디 빌드의 할당을 100만 번쯤에서 40번쯤으로 줄인다.
- **의사 난수 등급**: 등급 필드를 아예 없앤다(키에서 셈한다).

## 시험

명령 `go test`로 돌리는 `@(ziptree_test.go@>` 시험 파일이 하는 일이다.

- 논문의 그림 1을 정확히 되살린다.
- 세 표현을 교차 확인한다.
- BST와 힙 불변식을 퍼징으로 검사한다.
- 할당을 벤치마크한다.

## 빌드

```sh
make        # ziptree.go + ziptree_test.go + ziptree.pdf
make clean  # 생성물 삭제
```

규칙은 [../gweb.mk](../gweb.mk)에 있다.
