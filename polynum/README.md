# polynum

고정 다항체(폴리오미노)를 세는 Jensen의 전이 행렬 방법을 커누스가 구현한
것(2017)이다.

- 문서: [polynum.w](polynum.w)
- 바탕: 커누스의 CWEB 프로그램
- 그림: MetaPost 그림 하나(커누스의 `polyomino.mp`)

## 방법

- h×w 직사각형을 칸마다 훑으며, 줄 끝의 점유와 연결 성분을 `0 1 ( ) -` 다섯 글자
  짜임으로 묶는다.
- 최소-합 행렬 곱셈으로 셈한 연결 비용으로 쓸모없는 짜임을 잘라 낸다.
- 셈 자체는 하지 않고, 짝 프로그램 POLYSLAVE가 해석할 이진 명령어 파일을
  내놓는다.
- 짜임 풀을 위아래로 번갈아 굴리며 구멍까지 다시 쓴다.

## 원본과 다른 점

한 반복문에서 다른 반복문 몸통으로 뛰어드는 `goto`는 `case` 몸통을 함수 바깥
수준의 이름표로 펴서 옮겼다. 원본의 결함 셋을 고쳤다.

- n≥127이면 `char` 지수가 넘쳐 버스 오류로 죽는다.
- confsize가 0이면 배열 밖을 읽는다.
- slavesize가 2³⁰을 넘으면 명령어의 주소가 깨진다.

## 검증

- 파이썬 슬레이브로 세어 20칸까지 OEIS A001168과 맞았다.
- 원본과 실행 스무 가지에서 명령어 파일까지 바이트가 같다.
