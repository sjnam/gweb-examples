# hyperbolic

36°-45°-90° 삼각형으로 쌍곡 평면을 덮는 유일한 타일링을 셈한다.

- 문서: [hyperbolic.w](hyperbolic.w)
- 바탕: 커누스의 CWEB 프로그램
- 그림: MetaPost 그림 넷. [hyperbolic-arcs.mp](hyperbolic-arcs.mp)는 프로그램이
  뽑아내는 호의 좌표다.

## 방법

점은 상반 평면에 있고, "직선"은 실축에 중심을 둔 반원이다. 타일링 전체는 삼각형
하나에서 꼭짓점을 맞은편 변에 거듭 비추어(원에 대한 반전) 자라난다.

일을 사분 고리 하나로 줄이면 평면 전체에 삼각형 301개면 넉넉하다. 그 제한을
공짜로 만드는 요령은, 중심이 0인 수직 "원"을 두고 알고리즘이 그것을 넘지 않도록
하는 것이다.

이 삼각형 열 개가 정오각형을 이루니 마르겐슈테른의 오각 격자가 모습을 바꾼
것이고, 시작 좌표에 황금비가 마땅히 나타난다.

## 원본과 다른 점

커누스는 이웃 셈을 세 번 따로 쓰고, 호 667개를 손으로 `.mp` 파일에 옮겨 적었다.
옮긴 Go판은 셋을 첨자 붙은 반복문 하나로 접고, MetaPost를 스스로 뽑아낸다.

## 검증

호 667개가 모두 그의 것과 찍힌 마지막 자리까지 같다. 바탕 좌표는 컴파일러가
곱셈과 덧셈을 다르게 융합하는 탓에 3.3e-13까지 다른데도 그렇다. 그런데도 똑같은
타일링이 나오는 것이야말로 어름한 이진 탐색 사전을 둔 까닭이다.
