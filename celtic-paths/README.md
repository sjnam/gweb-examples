# celtic-paths

켈트 매듭을 찍는다. 정사각형 타일마다 모퉁이와 변의 가운데, 여덟 점을 잇는
선분을 하나나 둘 두어 고리를 짜면, 프로그램이 커누스의 전용 글꼴
CELTICA/CELTICB로 조판할 TeX 파일을 내놓는다.

- 문서: [celtic-paths.w](celtic-paths.w)
- 바탕: 커누스의 CWEB 프로그램(2026년 10월 29일 판)
- 그림: MetaPost 그림 하나

## 방법

- 흑백은 한 번 훑어 칠한다.
- 그림 바깥은 스택을 배열 안에 엮은 깊이 우선 탐색으로 찾는다.
- 엇갈리지 않는 두 선분의 가운데 영역은 둘레에서 두 토막으로 갈리므로 "마법의
  표"로 건너뛴다.

## 원본과의 관계

처음 옮긴 2017년 판에서 찾아 알린 것들이다.

- 배열 `codetable[0x1425]`를 두 번 대입해, 규칙에 맞는 타일 `1427`을 거절하는
  오타
- 배열 밖을 읽고 쓰던 곳
- 글꼴의 결함 둘: `0514`와 `0527`이 이웃 글자와 똑같이 그려져 끈이 끊긴다

커누스가 앞의 것들과 `0514`를 고쳤다. 글자 `0527`(자리 `0270`)은 아직 그대로라,
문서에 `.mf`의 고칠 줄을 적었다.

## 조판에 필요한 것

이 문서를 조판하려면 커누스 누리집의 `celtica.mf`, `celticb.mf`, `celtica13.mf`,
`celticb13.mf`를 TeX이 찾는 곳에 두어야 한다.

## 검증

- 원본과 입력 4525개에서 표준 출력, 표준 오류, 종료 부호가 바이트까지 같다.
- 안팎 칠하기는 합집합-찾기로 따로 구한 것과 302개에서 같다.

## 빌드

저장소 루트에서 부른다. 규칙은 [../Makefile](../Makefile)에 있다.

```sh
make celtic-paths  # celtic-paths/celtic-paths.go + celtic-paths/celtic-paths.pdf
make clean         # 모든 예제의 생성물 삭제
```
