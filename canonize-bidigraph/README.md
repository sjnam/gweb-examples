# canonize-bidigraph

양방향 그래프(변의 양 끝에 방향 기호 `<`나 `>`가 붙는 그래프)의 정규형을 구한다.
꼭짓점 몇 개를 *뒤집어*, 인접 행렬의 대각선과 그 위를 네 비트 부호로 늘어놓은
열이 사전식으로 가장 크게 되게 한다.

- 문서: [canonize-bidigraph.w](canonize-bidigraph.w)
- 바탕: 커누스의 CWEB 프로그램(2026년 10월 31일 판)
- 필요한 것: [go-sgb](https://github.com/sjnam/go-sgb)(그래프를 `gbsave`로 읽고
  쓴다)
- 그림: MetaPost 그림 하나

다섯 비트 무늬로 갈래를 고르는 커누스의 큰 `switch`를 경우별로 풀어 적고, 그
내력도 적었다.

## 원본과의 관계

1. 1월 판에서 결함 넷을 찾아 알렸다.
2. 커누스가 그것을 받아 알고리즘을 짝을 기억하는 합집합-찾기로 다시 짰다(10월
   28일 판).
3. 그 판을 전수 탐색과 견주어, `c10`과 `c01`을 셈하는 두 줄에서 `j`와 `k`가
   뒤바뀐 결함을 하나 더 찾아 알렸다.
4. 31일 판에서 고쳐졌고, 여기서 옮긴 것이 그 판이다.

## 검증

- 손대지 않은 31일 판과 표준 오류, 종료 부호, 저장된 그래프가 2100가지
  그래프에서 바이트까지 같다.
- 출력은 꼭짓점 둘과 셋의 그래프 전부에서 전수 탐색의 사전식 최댓값과 같다.

## 빌드

```sh
make        # canonize-bidigraph.go + canonize-bidigraph.pdf

```
