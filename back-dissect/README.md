# back-dissect

[back-dissect.w](back-dissect.w) — 정사각형을 칸 단위로 d개의
조각으로 잘라, 돌리고 밀어서 주어진 다른 모양을 채우는 방법을 모두 찾는다.
조각마다 옮김과 회전을 하나씩 정해 두면 남는 것은 이분 매칭이다. 옮김들이 모양을
덮는지부터 걸러 내고, 강제된 짝을 먼저 짓고, 그래도 남는 문제는 커누스가
DANCE에서 뜯어 온 춤추는 링크로 푼다. 4×9 직사각형의 계단 자르기가 두 조각으로
나오고, 4×4와 3×3을 나란히 놓은 모양을 5×5로 만들려면 조각이 이어져 있기를
바랄 때 네 조각이 든다는 것도 셈해 본다. 옮기다가 결함 둘을 만났다. 칸 하나짜리
모양에서 배열 밖 `s[-1]`을 읽고 죽는 것과, `fgets`의 37바이트 버퍼가 긴 줄을
쪼개 모양을 소리 없이 바꾸는 것이다. 원본과 무작위 모양 697개, 가장자리
32가지에서 출력과 종료 부호가 바이트까지 같고, 결함이 걸리는 9가지는 두 결함만
고친 원본과 같다. MetaPost 그림 둘.

## 빌드

```sh
make        # back-dissect.w -> back-dissect.go + back-dissect.pdf
make clean  # 생성물 삭제
```
