# 비스듬한 삼진 나무

크누스의 [skew-ternary-calc](https://www-cs-faculty.stanford.edu/~knuth/programs/skew-ternary-calc.w)를
한글 GWEB으로 옮긴 것이다. *비스듬한 삼진 나무*로 셈을 하고, 그것에 대응하는
*나눌 수 없는 평면 지도*를 내놓는다.

삼진 나무의 빈자리마다 *싹*을 놓는다. 뿌리 마디와 뿌리 싹의 계급은 0이고,
계급이 *r*인 마디의 왼쪽·가운데·오른쪽 자식은 각각 *r*−1, *r*, *r*+1이다.
모든 마디의 계급이 음이 아니면 그 나무가 *비스듬하다*. 예쁜 정리 하나가
바탕인데 — 고리처럼 같은 나무 2*n*+2개의 무리마다 비스듬한 것이 꼭 넷 들어
있다 — 증명이 놀랍도록 간단하다. 개미가 나무의 둘레를 기며 싹을 지날 때
상태를 올리고 호를 지날 때 내리면, 계급이 *k*인 싹에 이를 때 상태가 언제나
*k*다.

켤레 셋을 셈한 뒤 평면 지도를 두 길로 짓는다. Jacquard–Schaeffer 대응과
Del Lungo 들의 대응이고, 둘 다 Guibas–Stolfi의 quad-edge 구조 위에서 돈다.
크누스가 이 프로그램으로 얻은 놀라움 — 켤레 넷이 서로 *쌍대 지도*가 된다는
것, 그리고 Schaeffer에게 물었더니 제 1998년 학위논문에 답이 있더라는 이야기 —
도 그대로 옮겼다.

## 돌려 보기

```sh
make                              # tangle + 실행 파일 + 문서 조판
make run                          # 크누스의 보기 나무로 한 번
./skew-ternary-calc A-BD B--C C--- DE-F E--- F---
```

나무는 명령줄로 준다. 네 글자짜리 인자 `abcd`를 늘어놓는데, 첫 글자가 마디의
이름이고 이어지는 세 글자가 그 마디의 왼쪽·가운데·오른쪽 자식이다. 빈 자식은
`-`로 적는다. 마디마다 인자가 하나씩 있어야 하고, 차례는 아무래도 좋다.

## 손으로 만지작거리기

크누스는 더 나은 사용자 인터페이스를 만들 틈이 없었다고 사과해 두었다. 나무와
그래프를 손으로 만지작거릴 수 있는 대화식 프로그램이 있으면 좋겠고, 거기에 숨은
매혹적인 무늬들을 색으로 드러내면 더 좋겠다고. 그 바람의 첫 조각이
[app/index.html](app/index.html)이다.

```sh
make app                          # 기본 브라우저로 연다
```

판이 셋이다. **싹까지 드러낸 나무**는 크누스의 그림 1 그대로인데, 세로축을
깊이에서 계급으로 바꿔 볼 수 있다. 그러면 빨간 0선 아래로 마디가 하나도
내려가지 않는 것 — 곧 비스듬함 — 이 지형처럼 드러난다. **앨리스의 산책**은
개미를 한 걸음씩 걸리면서 상태표를 따라간다. 싹을 지나면 하나 쌓이고 호를
지나면 하나 빠지면서 초록 실로 맞붙는데, 한 바퀴를 다 돌고 나면 끝내 빠지지
않은 넷이 파랗게 남는다. 정리의 증명이 그대로 눈앞에서 돌아간다. **켤레 넷**
가운데 하나를 누르면 그 나무로 옮겨 간다 — 모양은 그대로이고 매다는 싹만
바뀌므로, 싹 번호는 새 뿌리에서 다시 매겨진다.

셈하는 부분은 `.w`의 「새기기」와 「상태표」 두 장을 자바스크립트로 옮긴 것이라
`setmate`의 goto까지 그대로 살아 있다. 무작위 비스듬한 나무 3510그루(마디
1\~39개)로 Go 프로그램과 맞춰 보았고, 나무 덤프·계급·싹 번호·켤레 셋 모두 한
글자도 다르지 않았다. 딸린 파일이 없는 한 장짜리 문서다 — 글꼴만 Google Fonts에서
가져온다.

평면 지도 쪽은 여기 없다. 그리려면 좌표가 필요한데 프로그램이 내놓는 것은
꼭짓점과 변과 면의 목록뿐이라, 그것은 옮기기가 아니라 짓기다. 크누스도 문서에
실은 그림 예순여덟 장의 좌표를 손으로 놓았다.

## 문학적 프로그래밍

원본은 [skew-ternary-calc.w](skew-ternary-calc.w) 하나다. 그림 예순여덟 장은
[skew-ternary-calc.mp](skew-ternary-calc.mp)에 `fig_...`라는 이름으로 들어
있고, 조판하는 동안 luamplib이 직접 그린다. 나머지는 전부 `make`가 만든다.

옮기며 손댄 곳은 다섯이고 모두 언어에서 왔다 — 매크로가 함수로, `root` 별명이
없어 `inputbud[1].parent`를 직접, 돌리기 ρ의 비트 재주를 뜻이 드러나는 꼴로,
쓰이지 않는 변수 셋을 제거, 종료 부호를 양수로. 「돌려 보기」장에 적어 두었다.
원본과는 씨앗마다 6333가지씩 맞춰 보았다 — 마디 62개까지의 무작위 비스듬한
나무, 나무가 아닐 수도 있는 무작위 인자 꾸러미, 잘못된 인자로 부르는 모든 길.

```sh
make doc                          # skew-ternary-calc.pdf — 47쪽, 그림 68장
make clean
```
