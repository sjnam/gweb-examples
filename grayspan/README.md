# grayspan

[grayspan.w](grayspan.w) — 그래프의 신장 나무를 모두 만들되, 이웃한 두 나무가
변 하나만 다르게 늘어놓는다. 맬컴 스미스의 석사 논문(1997)을 바탕으로 커누스가
"조금 서둘러" 짠 것이다. 거의 나무의 첫 변을 줄여 되부르고, 끝나면 그 변을
지워(다리가 아닐 때만) 다시 되부른다. 줄이기와 펴기는 이중 연결 리스트 위의 춤추는
고리로 하고, 다리는 차수 1과 나란한 변이라는 어림 둘에 이어 너비 우선 탐색으로
가린다. 한 반복문에서 다른 반복문 몸통으로 뛰어드는 `goto`는 첫 반복문을 이름표로
펴서 옮겼다. 덩치 큰 go-sgb 레코드 대신 작은 꼭짓점·호 구조체로 옮겨 담는다. 원본의
결함 하나, 꼭짓점이 없는 그래프에서 세그폴트로 죽는 것을 고쳤다. 그래프 396개에서
세 가지 자세함으로 원본과 출력·mems가 바이트까지 같고, 행렬 나무 정리와 그레이
성질로 따로 검사했다. 전역이던 `mems`를 지역 변수로 옮기자 1.4배 느리던 것이 원본보다
1.4배 빨라졌다.

## 빌드

```sh
make        # grayspan.w -> grayspan.go + grayspan.pdf
make clean  # 생성물 삭제
```

규칙은 [../gweb.mk](../gweb.mk)에 있다.
